# Online PBR lantern rendered by Pentool

This example uses the **Lantern** GLB from Khronos' glTF Sample Assets. The
catalog describes it as an old wooden street light and credits Microsoft,
sbtron, and Frank Galligan under CC0 1.0.

- Catalog: <https://github.com/KhronosGroup/glTF-Sample-Assets/blob/main/Models/Models-core.md>
- Source GLB: <https://raw.githubusercontent.com/KhronosGroup/glTF-Sample-Assets/main/Models/Lantern/glTF-Binary/Lantern.glb>
- License: <https://creativecommons.org/publicdomain/zero/1.0/>

`lantern.pen` keeps the downloaded GLB as a verified relative source so the
camera, lighting, environment, materials, frame and quality remain editable.
