# v0.28.0 (in progress)

- `pentool watch DOC`: one JSON line per change with the actor and the ids of
  added, changed and removed objects, for agents that react to each other's edits.

  JSON data files (bar, column, segmented, table, stat tiles, callouts), with
  numbered citations, a generated Sources page and `check --strict`.
  See `docs/reports.md`.
- Studio: selections show their true shape; selection brush (see roadmap).
