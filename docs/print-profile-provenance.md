# Print reference profile provenance

`fixtures/print-CGATS21_CRPC7.icc` is the original 3,462,496-byte
CGATS21_CRPC7 profile provided by Idealliance, copyright X-Rite, Inc.
The bytes have not been altered. SHA-256:
`2b186e6dadc38883138ccd30203b2870fb71db6451d3a5d24f9590cfabd26689`.

The [ICC registry entry](https://registry.color.org/profile-registry/CGATS21_CRPC7)
permits use, embedding, exchange and sharing. Alteration and sale require
Idealliance's written permission. The repository's code licenses do not
relicense this profile. Retain the original embedded copyright/license notice
and these provenance details with any redistribution. This is a reference
fixture, not a universal recommended press condition or a built-in print recipe.

The [original download](https://registry.color.org/profile-registry/profiles/CGATS21_CRPC7.icc)
was retrieved on 2026-10-09. Its complete size is intentional: testing a real
printing condition complements the tiny authored probes, and trimming it would
both change its license-protected bytes and remove the real transform tables.
The profile includes all six A2B/B2A paths and supplementary gamut/CxF metadata.
It is test data, not a native runtime dependency or compiled-in binary resource.

`fixtures/print-press-vectors.json` records independent LittleCMS 2.18 results
for four intents, in both directions, through Pillow 12.2.0. It also records
42 direct A2B/B2A pipeline evaluations through LittleCMS's public C API,
64 authored-RGB/real-press linked vectors and eight v2-CMYK/real-press links.
Regenerate with
`python scripts/reference-print-press.py --lcms-library <development-library>`, then
`python scripts/generate-print-fixtures.py` to repin the vector manifest.
Both operations are offline and require the unmodified fixture already present.
The shared library is a development reference built separately from the
[LittleCMS 2.18 source](https://github.com/mm2/Little-CMS/tree/lcms2.18),
using its unmodified `src/*.c` and `include/` headers. For example, with GCC:
`gcc -shared -O2 -I include src/*.c -o lcms2.dll -lm`.
It is never linked to Pentool or needed to run its Rust tests.
Neither script modifies the profile. The vectors compare against LAB8/CMYK8
with LittleCMS NOOPTIMIZE, avoiding its additional fast 8-bit resampling. The
initial optimized vectors were deliberately replaced after dark-color probes
exposed that resampling difference. Tolerances remain unchanged and allow
quantization; they do not claim bit-identical results between CMMs. Direct
pipeline comparisons use a separate normalized tolerance of 0.0002 (about
13 16-bit steps), accounting for the reference's intermediate fixed-point
rounding and curve evaluation versus Rust's f64 evaluation. This does not
change the linked LAB8/CMYK8 tolerances. The draft
uses tetrahedral 3D interpolation and linear interpolation between tetrahedral
4D slices, matching the reference interpolation convention.

The Rust tests compare all six direct pipelines and all four linked intents in
both directions. LittleCMS applies black mapping at a v4 perceptual/saturation
destination even without a requested BPC flag. A physical PCS destination does
not request this additional mapping. The separate Rust `Link` planner records
the policy and mapping; individual table execution remains independently checked.
The v2 CMYK probe has black L*=10 and legacy `desc`/`text` metadata, exercising
detected source black rather than an assumed zero. All five authored probes
also pass the independent endpoint checks in `check-print-probes.py`.

The authored `print-rgb-linear-*`, `print-cmyk-lut16-*` and `print-cmyk-mab-*`
profiles are separate CC0-1.0 numerical probes generated by Pentool. They do not
characterize a physical printing process. Their fixture vectors use a tighter
numerical tolerance, except the mAB probe's explicitly bounded 16-bit
quantization error.
