# Stabilization (0.20.x)

Audit reports and follow-up task lists for the patch-release phase described in
`AGENTS.md`. Each `audit-*.md` is written by an auditor, each `TASKS-*.md` is the
hand-off for the agent that fixes what the audit found. `TASKS.md` is the merged,
prioritized queue.

Severity: P0 data loss or corrupt `.pen`; P1 documented feature broken; P2 wrong
output or missing test/doc/help; P3 polish.
